## 이 표는 batch_size=1 로 뽑습니다 (2026-09-25 이후)

`facebook/wav2vec2-base` 는 `feat_extract_norm="group"` 이라 conv 특징
추출기의 GroupNorm 이 **시간축 전체**를 정규화합니다. 0 패딩이 그 통계에
들어가면 유효 프레임의 출력까지 바뀌고, `attention_mask` 는 트랜스포머
층에서만 작동해 되돌릴 수 없습니다. 그래서 **같은 체크포인트의 WER 이
발화를 몇 개씩 묶느냐에 따라 달라집니다.**

같은 체크포인트 · 같은 192발화 · 배치 설정만 바꾼 실측 (2026-09-25):

    RNN-T  bs=1  (패딩 없음)        0.04712   <- 배치와 무관한 유일한 값
    RNN-T  bs=8  패딩+마스크        0.04852   +3.0%
    RNN-T  bs=8  마스크 없음(HF권고) 0.04992   +5.9%
    RNN-T  bs=32 패딩+마스크        0.06018   +27.7%
    CTC    bs=1                     0.04922
    CTC    bs=8  (현재 기본값)       0.05202   +5.7%

그래서 이 표는 **`--batch_size 1` 로 뽑은 줄만** 받습니다. 이전
bs=8/32 결과는 `results/DISCARDED_bs8/` 로 옮겼습니다 -- 상대
비교는 유효하지만 절대값이 틀립니다.

**방법 간 비교는 무너지지 않습니다.** 모든 셀이 같은 배치 설정으로
평가됐고, 평가 데이터셋에 셔플이 없어 배치 구성이 재현됩니다 -- 같은 셀을
다른 실행에서 두 번 돌려 소수점 다섯 자리까지 일치하는 것을 확인했습니다.
그래서 `Δ vs baseline` 열은 유효하고, 틀린 것은 WER 의 절대 크기입니다.

논문에 절대값을 실으려면 `--batch_size 1` 로 다시 뽑아야 합니다. 실측
비용: CTC 2.77, RNN-T 3.04 코어·초/발화 (2스레드가 코어당 최고 효율).

**SlimDucer 는 무관합니다** -- AuT 는 conv 추출기가 없고, WavLM-Large 는
`feat_extract_norm="layer"` 라 시간축 통계를 쓰지 않으며, whisper 는 항상
30초 고정 패딩입니다. 유일하게 해당되는 wav2vec2-base 인코더 런은 이미
폐기됐습니다.

## 들어올 수 있는 줄의 조건

1. **`wav2vec2_inference.py`** (CTC) 또는 **`rnnt/eval_ckpt.py`** (RNN-T) 의
   출력일 것. 훈련 루프 eval 값은 제외 — 같은 체크포인트 60셀 실측으로
   훈련 로그가 평균 **+0.39%** 높습니다(HF Trainer 가 평가에도 bf16
   autocast 를 걸기 때문). 100h LS 효과(−1%)와 같은 크기라 섞으면 비교가
   무너집니다.
2. **greedy** (`--decoder pipeline`). beam_search 는 test-clean −0.67% /
   test-other −0.72% 로 계통적으로 좋아서 같은 표에 못 들어갑니다
   (같은 체크포인트 144쌍 실측, test-other 는 71/71 에서 beam 이 이김).
3. **test-clean / test-other 전체**. dev 는 안 받습니다.
4. **방법은 체크포인트 디렉터리 접미사로 판정**. 태그를 믿지 않습니다.

   | 접미사 / 조건 | 방법 |
   |---|---|
   | `alpha_0p0` | baseline |
   | `_classspace` (fas 없음), beta=0 | LS (전통, class space) |
   | `_classspace_fas_eps1eneg10`, **beta=1.0** | LS (textbook 과 bit-exact) |
   | `_classspace_fas_eps1eneg10`, beta=0.0 | FAS |
   | `_aws_eps1eneg10_hmatch` | AWS |

   `watch_decode_cpu.sh:72` 는 beta 만 보고 `LS/FAS` 를 붙이므로 **AWS 런이
   전부 `FAS_` 태그로 기록돼 있습니다.** decode.jsonl 의 태그를 그대로
   읽으면 안 됩니다.

5. 장치는 무관합니다. `wav2vec2_inference.py` 는 autocast/bf16 이 없어
   항상 fp32 이고, 같은 체크포인트에서 CPU 와 CUDA 가 소수점 17자리까지
   같았습니다. GPU 가 9배 빠릅니다.

⚠ 표시는 5시드가 안 찬 칸입니다.
