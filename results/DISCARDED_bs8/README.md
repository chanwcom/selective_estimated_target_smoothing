# 폐기된 배치 오염 결과 (2026-09-25)

여기 있는 파일은 **쓰지 마십시오.** `batch_size` 8 또는 32 로 뽑혀서
절대 WER 이 부풀려져 있습니다.

`facebook/wav2vec2-base` 는 `feat_extract_norm="group"` 이라 conv 특징
추출기의 GroupNorm 이 시간축 전체를 정규화합니다. 0 패딩이 그 통계에
들어가면 유효 프레임의 출력까지 바뀌고, `attention_mask` 는 트랜스포머
층에서만 작동해 되돌릴 수 없습니다.

실측 (같은 체크포인트, 같은 192발화, 배치 설정만 변경):

    CTC    bs=1 0.04922   bs=8  0.05202   +5.7%
    RNN-T  bs=1 0.04712   bs=8  0.04852   +3.0%
                          bs=32 0.06018  +27.7%

대체본은 `results/bs1_test/results.jsonl` 입니다 (batch_size=1, 패딩 없음).

지우지 않고 남겨둔 이유: 모든 셀이 같은 배치 설정이므로 **방법 간 상대
비교(Δ)는 유효**합니다. bs=1 결과가 다 차기 전까지 참고할 수 있고, bs=1
값과 짝지으면 배치 효과의 독립 추정치가 됩니다.
